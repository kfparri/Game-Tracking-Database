# README

This Project is a simple project I started to do three main things, the first was simple.  I wanted a local application that I could use to track all the different games that I own in one place.  I know there are apps and sites that do that already, but I wanted something local that I could run and would allow me to be flexible in the way I wanted to be.  To that end I wanted an app that could track all types of games (not just video games).

The second thing I wanted to do was to become more comfortable with and try to develop techniques to integrate using different AI platforms into my workflow.  Not true vibecoding (that's not really my thing), but trying to find a good balance of using AI tools to speed up software development without relying entirely on those tools.  The focus for me was to use it to help me keep in the bounds of good design (I'm terrible about doing it the "right way") as well as helping me make the UI look sleek and modern (another thing I'm not any good at...).  I used Claude to help build the UI, and properly design the MVVM aspects of this program to help me learn how to make good MVVM applications.

The third goal of this project was to just overall improve my exposure to these technologies.  I've never used FastAPI and I have very little XAML experience.  This program is an exercise to help me get more comfortable with those technologies.
